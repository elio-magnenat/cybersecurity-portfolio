# Web Security

This section contains my web application security notes and practical lab write-ups.

The material is organized into two main areas:

- [API Testing](api-testing/README.md) — API reconnaissance, endpoint discovery, hidden parameters, mass assignment, server-side parameter pollution, and related labs.
- [Web Vulnerabilities](vulnerabilities/README.md) — vulnerability-focused notes covering attack patterns, impact, testing approaches, prevention, and practical labs.

## Organization

```text
web-security/
├── README.md
├── api-testing/
│   ├── README.md
│   ├── topic notes
│   └── labs.md
└── vulnerabilities/
    ├── README.md
    └── one folder per vulnerability family
```

Theory is kept separate from lab write-ups when a topic becomes large enough to benefit from the split.
